# 🍽️ Restaurant Menu Template

A **free, open-source, single-file** digital menu with a shopping cart and **WhatsApp ordering**. No build step, no dependencies, no backend — just one `index.html` file you can host anywhere.

> Built and maintained by **[Nukhba Studio](https://younisgaith1-ctrl.github.io/nukhba-site/en.html)** — we build custom websites, stores and ordering systems.

---

## ✨ Features

- 📱 Mobile-first, loads instantly (single file, zero dependencies)
- 🗂️ Categories with filter tabs
- 🛒 Cart with live total
- 💬 **Order via WhatsApp** — the cart is formatted into a WhatsApp message
- 🎨 Clean dark theme, easy to re-brand
- 🌍 Works in English and Arabic (`CONFIG.language`)
- 🆓 MIT licensed — free for personal and commercial use

## 🚀 Quick start

1. Download `index.html`.
2. Open it in any editor.
3. Edit the `CONFIG` object (name, WhatsApp number, currency, language).
4. Edit the `DATA` array with your categories and items.
5. Host it (GitHub Pages, Netlify, Vercel, or any static host).

```js
const CONFIG = {
  restaurant: "Your Restaurant Name",
  tagline: "Fresh food, made with love",
  whatsapp: "1234567890",   // international format, digits only
  currency: "$",
  language: "en"            // "en" or "ar"
};
```
